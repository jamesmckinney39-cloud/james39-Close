THE CLOSE — GitHub upload package
=================================

This folder is ready to upload to a GitHub repository for GitHub Pages.

Contents:
  index.html     Site (edit SITE config — search EDIT ME)
  images/        Photos
  music/         MP3 audio (replace with your songs)
  videos/        MP4 video (replace with your videos)
  favicon.svg
  HOW_TO_PUT_THIS_ON_WIX.txt   Full instructions
  WIX_FIELD_CHEATSHEET.txt     Config field list

Quick start:
1. Create a PUBLIC GitHub repo (e.g. the-close)
2. Upload EVERYTHING in this folder to the repo ROOT
   (index.html must be at the top, not inside another folder)
3. Settings → Pages → Deploy from branch → main → / (root) → Save
4. Open https://YOUR-USERNAME.github.io/the-close/
5. In Wix: Add → Embed Code → Embed a site → paste that .github.io link

Full steps: open HOW_TO_PUT_THIS_ON_WIX.txt
